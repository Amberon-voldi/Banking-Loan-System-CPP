CSS Math Functions Demo

max() Function

Selects the largest value. Useful for setting minimum sizes responsively.

Width: max(50%, 300px) - At least 300px or 50% of container
width: max(50%, 300px);

min() Function

Selects the smallest value. Useful for setting maximum sizes responsively.

Width: min(100%, 500px) - Maximum 500px or 100% of container
width: min(100%, 500px);

clamp() Function

Sets a value between a minimum and maximum. Perfect for responsive designs.

Width: clamp(200px, 50vw, 800px) - Between 200px and 800px
width: clamp(200px, 50vw, 800px);

Flexible Typography

Font sizes scale smoothly between minimum and maximum values

font-size: clamp(0.9rem, 1.5vw, 1.2rem);

Smart Spacing

Padding adapts to viewport while staying within bounds

padding: clamp(1rem, 2vw, 2rem);

Responsive Width

Width stays between constraints and adapts to screen
